# Third-party components

This demo uses the existing local OpenCV 4.5.4 Windows x64 SDK. Its Apache 2.0 license is included as `OpenCV-LICENSE.txt`. OpenCV is Copyright (C) the OpenCV contributors and the copyright holders identified in its distribution.

OpenCV's bundled codec and support-library license files are preserved under `opencv-thirdparty` from the SDK source distribution. The demo does not use video I/O plugins. The CIEDE2000 implementation is original code tested against numerical examples published by G. Sharma, W. Wu, and E. N. Dalal, “The CIEDE2000 Color-Difference Formula: Implementation Notes, Supplementary Test Data, and Mathematical Observations,” Color Research and Application 30(1), 21–30, 2005. See https://hajim.rochester.edu/ece/sites/gsharma/ciede2000/.

.NET and Microsoft Visual C++ runtimes are system prerequisites and are not redistributed in this folder.
