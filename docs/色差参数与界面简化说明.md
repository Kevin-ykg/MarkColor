# 色差参数与界面简化（2026-10-16）

> 历史功能/验证记录：以下数据和路径描述当时环境，不代表当前版本已重新验收。当前入口与契约请以 [项目全局导航与开发指南](项目全局导航与开发指南.md) 为准。

## 设置 kL / kC / kH

打开 **设置 / 微调标准 → ΔE00 参数**，分别填写明度、彩度和色相参数因子，点击应用后立即重新比较。默认均为 1，允许 0.1–10；零、负数、NaN、无穷值及越界值会被拒绝。需要保存时点击 **标准文件 → 保存标准**。

因子越大，对该分量越不敏感；它们不是 L/a/b 的百分比。修改因子不会改变取色 Lab、圆点对应关系或逐点阈值；已有 `|ΔL|/|Δa|/|Δb|` 附加限值仍然独立生效。详细含义和现场验证方法见 [ΔE00 权重与光照一致性](ΔE00权重与光照一致性说明.md)。

仅修改色差因子时复用已有测量结果，不再读图或提取轮廓；多次采样的最大色差统计也同步更新。修改记录包含参数前后值。HTML 显示实际因子，CSV 在原 37 列后追加 kL/kC/kH 三列；已有列的顺序保留。

## 主界面

顶部常用按钮采用 16 号字、半粗体、至少 44 像素高度。标题区压缩，更多空间留给图像。

| 操作 | 新位置 |
|---|---|
| 加载待测图像 | 顶部主按钮 |
| 多图采样建标、单图建标、当前图设为标准 | 建立标准菜单 |
| 保存、读取、清除标准 | 标准文件菜单 |
| 调整参数、批量检测、导出报告 | 顶部直接操作 |
| 同步左右图、掩膜、轮廓、适应窗口 | 显示选项 |
| 原始 Lab、通道差、像素波动 | 勾选“展开 Lab 明细” |
| 质量证据、选中点原因、几何变换 | 展开“检测依据与配准详情” |

默认结果表显示编号、颜色、名称、墨路、ΔE00、阈值、结论。主界面持续显示实际 k 参数，避免使用自定义因子时看不出当前判据。图像路径、尺寸和标准版本可通过标题提示查看；重要检测结论和错误不会因折叠明细而隐藏。

## 维护入口

| 内容 | 文件 |
|---|---|
| 权重模型、范围验证与深复制 | `Models/ColorDifferenceSettings.cs`、`Models/DetectionSettings.cs` |
| 参数设置页与草稿输入 | `SettingsWindow.xaml`、`SettingsWindow.xaml.cs` |
| Native 新接口及错误边界 | `native/include/mark_color.h`、`native/src/mark_color.cpp`、`Native.cs` |
| 公式与交互修正项 | `native/src/color_difference.cpp` |
| 几何匹配及对应后取色差 | `native/src/mark_matching.cpp` |
| 主界面展示层级 | `MainWindow.xaml`、`MainWindow.Presentation.cs` |
| 设置提交与结果替换 | `MainWindow.xaml.cs` 的 `ApplySettingsAsync` |
| 参数和界面回归 | `tests/Verification/ColorFactorTests.cs`、`native/tests/native_tests.cpp` |

Native ABI 与标准格式均升级为 3。C ABI 保留旧比较接口的 1/1/1 行为，新界面使用显式接收色差参数的接口。旧标准读取后默认补齐参数，新标准保存为 v3，防止旧程序无声忽略 k 参数。

源码整理包含命名空间逐层缩进、明确配准变量名、常量/数组/坐标的用途与单位说明。`format.ps1 -Check` 检查工程自有源码和构建文件；第三方库与生成代码不改动。几何算法与检测阈值没有因代码整理而放宽。
