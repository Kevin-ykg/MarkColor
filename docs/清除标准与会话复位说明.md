# 清除标准与会话复位

> 历史功能/验证记录：以下数据和路径描述当时环境，不代表当前版本已重新验收。当前入口与契约请以 [项目全局导航与开发指南](项目全局导航与开发指南.md) 为准。

“标准文件 → 清除标准并重置”用于结束当前检测会话，换一张不同位置/版式的图片重新建标。

点击后：

- 清空当前内存中的标准、标准图、待测图、检测结果、选择和旧错误提示。
- ROI 恢复为全图（X=0、Y=0、宽=1、高=1）。提取、配准、测量质量、默认色差阈值及 kL/kC/kH 全部恢复程序默认值。
- 清空旧图像的 ROI 拖框、选择和缩放；恢复默认的轮廓、取色区、同步和明细显示选项。
- “设置 / 微调标准 → ROI / 预览”不再带入旧图片。可直接选择新的单图或多图样本建标；新图需要限定膜片时，按提示重新框选。

**磁盘上保存的标准 JSON 不会删除或修改。** 当前标准有未保存修改时，仍先提示保存、放弃或取消；取消会保留当前会话。之后读取已保存 JSON 会恢复其中保存的 ROI 和参数，这是有意恢复旧标准的行为。

普通“适应窗口”只调整缩放和平移，不清除当前 ROI。只更改阈值并刷新同一张图时，也保留视图操作状态；换图或清空图像才移除属于旧图坐标的拖框与选择。

## 原因与源码入口

旧 `ClearStandard_Click` 只清空 `standard`、`standardAnalysis` 和 `inspection`，没有重置 `settings` 和 `current`。下一次建标继续使用旧 ROI，设置对话框也继续从旧待测图取得预览。

- `src/MarkColorDemo/MainWindow.xaml.cs`：完整会话复位；先检查忙碌和未保存状态。
- `src/MarkColorDemo/ImageViewport.cs`：更换图像时清除旧坐标系的交互状态。
- `src/MarkColorDemo/MainWindow.xaml`：菜单名称和提示说明清除范围。
- `tests/Verification/ClearStandardTests.cs`：真实设置提交、清除事件、旧 ROI 外的新图重新建标及磁盘文件保护回归。

## 验证

以 `优良品/2-上.bmp` 建标，通过实际设置应用流程提交 Y=0.1、高度=0.3 的 ROI，并调整内圈、色差因子和质量阈值。先确认该 ROI 下 `2-下.bmp` 检出 0 点，再调用真实清除事件。修复前在“全部参数恢复默认”断言失败；修复后全部参数与新建默认对象一致，两侧图像和设置预览均为空，随后 `2-下.bmp` 直接建标成功，检出 5 点。

同时覆盖无标准但已修改参数、忙碌期间拒绝清除、同图刷新保留 ROI、换图清除拖框，以及旧 JSON 内容不变且仍能读取。既有 99 张图、231 点及标准/报告/WPF 回归通过；Release 发布目录已更新。

修复前后日志位于 `verification/clear-standard-reset/`，清除后的界面截图为 `verification/clear-standard-preview.png`。
