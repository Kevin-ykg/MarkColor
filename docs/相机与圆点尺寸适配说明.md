# 相机与圆点尺寸适配（2026-10-15）

> 历史功能/验证记录：以下数据和路径描述当时环境，不代表当前版本已重新验收。当前入口与契约请以 [项目全局导航与开发指南](项目全局导航与开发指南.md) 为准。

> 后续更新：建标失败现可直接进入 ROI 调整，无须先加载待测图；性能改动和实测见 [建标恢复与性能优化说明](建标恢复与性能优化说明.md)。

## 问题定位

新相机 `MVS/Data` 中的图像为 5472×3648；主体膜片圆点实测半径约 48–51 px。旧图库典型图像为 2448×2048、半径约 70 px。新圆点仍在原来 25–160 px 的范围内，所以本批漏检并非单纯由最小半径造成。

新图的暗色、偏蓝膜片背景也满足旧算法的“低灰度 / 高饱和度”条件，导致圆点与背景连通。灰度相近但颜色不同的圆点也容易被灰度补充分支漏掉。ROI 只改变检测区域，不改变原图像素单位或圆点半径。

## 本次实现

- 保留原彩色、深色、弱对比度分割，追加 B/G/R 分通道、多尺度 Canny 闭合边缘候选。每层约覆盖 4–40 px 半径，逐层缩小；尺度由半径范围决定，不能因整图更大而把小圆点过度缩小。
- 将候选映射回原图后局部精修，复核实心圆填充率、圆度、边缘支持及置信指标。边缘图仅用于定位，不用于 Lab 取色。
- 宽尺寸模式同时保留中尺度的局部背景估计，避免把最小半径调小后，大而接近白色的缺墨圆点反而漏检。
- 新建设置默认半径范围 8–500 px、最小圆填充率 0.80，精修后再次核对几何。原生参数仍允许 3–2000 px；范围边界允许半像素的离散化偏差。小圆点使用较小的形态学核，避免固定 5×5 开运算吞掉细小结构。
- 旧标准中保存的参数保留。打开“设置 / 常用设置”，点击“扩展圆点尺寸：8–500 px”可迁移到宽范围，并把圆填充率提高到至少 0.80，然后到“ROI / 预览”查看结果；该按钮不会重置 ROI 或颜色阈值。
- 预览显示实际半径范围、最少取色像素数及质量失败原因。圆点可定位不代表颜色一定可可靠测量；原有质量门槛继续生效，未放宽色差阈值。
- 检测/显示最多允许 256 个候选，单膜片标准和配准仍限制为 16 点。超出 16 点时保留图像与候选，提示缩小 ROI；不截取“前 16 点”冒充完整检测，不进入组合匹配器。

## 使用步骤

1. 关闭正在运行的旧版 Demo，重新打开项目 `run.cmd`。在 VS 中运行时，先停止旧进程，再重新生成。
2. 清除旧相机的标准，加载新相机图像；如果已有标准尚未保存，按界面提示先保存。
3. 视野包含多张膜片、二维码或手部时，在设置的 ROI 页框选**目标膜片的全部圆点**，边缘留出余量。ROI 太紧会截断圆点；不要用不断缩小 ROI 代替圆点尺寸设置。
4. 先预览圆点数、半径及质量，再应用；用新相机固定曝光、白平衡、光源下拍摄的 OK 图重新单图或多图建标。

更换相机和视野后，不应直接沿用旧相机的 Lab 目标值。分辨率缩放无法补偿视野比例、镜头、曝光、颜色响应的变化；本次未自动修改配准容差或颜色阈值。

## 回归入口

```powershell
.\build.ps1 -Configuration Release
.\verify.ps1 -Configuration Release
.\build\verification\Release\Verification.exe --camera-scale 'C:\Users\EDY\MVS\Data' 'E:\南京爱速智\2.0设备成像方案\色差\条形膜片'
```

- `native/tests/scale_tests.h`：8、12、24、50、90、180、350、500 px 半径，浅色/深蓝背景，混合尺寸，ROI 坐标与 Lab 一致性，显式半径限制及 20 点预览。
- `tests/Verification/CameraScaleTests.cs`：新图库 38 张（BMP 中央目标使用人工 ROI，JPEG 全图）、旧条形图库 144 张，独立预期点数及 WPF 实际绑定/渲染。新图目标膜片为 7 点；旧图为 1 或 5 点。
- 原项目 99 张图库继续检验点数、上下偏移、匹配歧义、缺点、质量状态和报告一致性。
- 验证输出在 `verification/camera-scale/`；`camera-regression.json` 记录每张图的参数、点数、原图坐标、半径、样本量、质量失败数及耗时。只有 `Failures` 为空才通过。

这些测试覆盖现有样本与合成尺度变化，不代表任意材料、任意照明或低于有效采样分辨率时都能检测。扩大尺寸范围会增加搜索开销；已知尺寸时可收窄上下限、限定目标 ROI，但颜色始终在原始像素上测量。
