# 图标、缩放与格式维护

## 图标

CMYK 四圆点和放大镜组成应用标识，用在 EXE、主窗口、设置窗口及主界面标题区。

- `src/MarkColorDemo/Assets/CmykIcon.xaml`：矢量源，标题区直接使用。
- `src/MarkColorDemo/Assets/CmykMark.ico`：Windows 图标，内含 16、20、24、32、40、48、64、128、256 像素版本。
- `src/MarkColorDemo/Assets/CmykMark.png`：256 像素预览。
- `MarkColorDemo.csproj` 的 `ApplicationIcon`：将 ICO 编译进 EXE。

修改矢量源后，在项目目录执行：

```powershell
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File .\build-support\generate-icon.ps1
.\build.ps1 -Configuration Release
```

图标已经提交到项目文件夹，正常构建无需再运行生成脚本。

## 图像缩放

`ImageViewport.cs` 集中控制所有图像视口：

- 每一整格滚轮放大 1.35 倍，反向除以 1.35；高分辨率滚轮按实际增量处理。
- 缩放范围由原来的 1–12 倍改为 1–64 倍，基准是“整图适应当前窗口”的显示比例。
- 缩放围绕鼠标位置进行，左键拖动平移，双击恢复适应窗口；圆点聚焦也采用同一倍率上限。
- 放大只改变显示坐标，不增加图像细节、不改变原图 Lab 取样像素；高倍率下可见像素块是正常现象。

`tests/Verification/ViewportInteractionTests.cs` 检查滚轮增量、鼠标锚点、同步视图、上下限及 ROI/复位坐标。

## 格式检查与注释

本轮统一了工程自有 C++、C#、XAML/工程 XML 和 PowerShell 的缩进及布局，重点补齐控制分支大括号、成员间空行和长参数表续行缩进。第三方库和生成目录不属于整理范围。

关键注释解释了：几何匹配为什么不能依赖颜色、质量失败如何覆盖色差判定、Native 质量证据如何对应圆点、批量检测与报告队列为何限流、ΔE00 的参数含义，以及显示缩放与测色像素的区别。更多维护约束见 [代码规范](代码规范.md)。

```powershell
.\format.ps1
.\format.ps1 -Check
```

整理前的源码归档和数值基线位于 `verification/appearance-format/`。格式检查只覆盖可自动执行的布局规则，业务命名与复杂表达式仍需代码审查。

关于光照变化与亮度贡献，见 [ΔE00 权重与光照一致性](ΔE00权重与光照一致性说明.md)。本轮保持标准 ΔE00 参数与判定阈值不变。
