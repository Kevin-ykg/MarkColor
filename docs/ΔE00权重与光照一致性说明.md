# ΔE00 权重与光照一致性

## 当前实现

`native/src/color_difference.cpp` 的 `calculateDeltaE00` 使用 CIEDE2000，参数因子默认 **kL = kC = kH = 1**。现在可在 **设置 / 微调标准 → ΔE00 参数** 中分别调整，范围为 **0.1–10**。这个范围是 Demo 的输入约束，不代表经现场验证的推荐范围。默认阈值保持原值。

输入后点击“应用设置并重新检测”，然后通过“标准文件 → 保存标准”持久化。参数属于整个标准，所有 mark 共用；修改因子仅重新比较已有 Lab，不重复提取图像。主界面、HTML 和 CSV 均显示实际使用的参数。

标准格式升级为 v3：v1/v2 标准仍可读取，缺少参数时补齐 1/1/1；新版保存为 v3，使旧程序拒绝读取，防止旧程序忽略自定义参数后误判。Native ABI 升为 3，需同步更新 WPF 与 DLL；统一解决方案会自动生成并复制。

ΔE00 不是 L、a、b 各占三分之一，也不是给三个 Lab 差值指定百分比。它由 Lab 计算明度差 ΔL′、校正彩度差 ΔC′、校正色相差 ΔH′，并使用随颜色变化的尺度 SL、SC、SH 及交互修正 RT：

```text
uL = ΔL′ / (kL · SL)
uC = ΔC′ / (kC · SC)
uH = ΔH′ / (kH · SH)
ΔE00 = sqrt(uL² + uC² + uH² + RT · uC · uH)
```

因此 a* 和 b* 并不是两项独立权重。权重含义与公式可核对作者提供的 [实现说明和测试数据](https://hajim.rochester.edu/ece/sites/gsharma/ciede2000/) 及 [论文公式](https://www.ece.rochester.edu/~gsharma/ciede2000/ciede2000noteCRNA.pdf)。

## 是否减弱 L 的影响

同一个合格圆点移动到暗角，L* 可能变化，因此这个问题需要考虑。但建议先降低位置引起的成像差异，再讨论判据容差。照明变化也可能改变 a*、b*；不能默认它只影响亮度。

从公式看，在其他因素不变时，将 kL 从 1 增大到 2，会把归一化明度项 uL 减半，其平方项减到四分之一。**只有纯明度差时，总 ΔE00 才恰好减半**；不能把这解释为“L 占 50%”，也不能把 kL 增大误解为提高亮度敏感度。

在当前喷墨应用中，真实出墨变少也可能让圆点变亮，尤其 K 点容易主要体现为明度变化。如果随意压低明度贡献，会同时放过这类缺陷。没有现场 OK/NG 样本验证，不能给所有墨路规定统一的 L 占比。

## 建议的现场验证顺序

1. 固定光源、曝光、增益、白平衡和输出处理链，记录相机型号、位深、色彩模式及配置；避免自动调整把位置变化与相机自适应混在一起。
2. 同一张确认合格的膜片，在中心、四角和边缘重复采样；分别记录各 mark 的 L*/a*/b*、ΔL*/Δa*/Δb*、位置、质量结论与重复波动。多图平均标准能降低随机波动，但不会自动修正空间上稳定存在的明暗偏差。
3. 若偏差与位置稳定相关，优先评估照明均匀性、镜头暗角及平场校正。平场应在合适的线性数据域按相机流程实施，不能直接把每个圆点的 L* 强行拉到标准值。Basler 的 [平场校正文档](https://docs.baslerweb.com/flat-field-correction) 说明了对传感器、照明及光学不均匀性的校正用途；具体接口取决于实际相机能力。
4. 若仍有可接受的明度波动，再离线比较 kL=1、1.2、1.5、2 等候选配置，初步保持 kC=kH=1。这只是试验网格，不是生产推荐值。同时验证独立采集的正常样本与各墨路欠墨/过墨样本，统计误报率、漏检率，尤其检查 K 点。
5. 参数与 ΔE00 阈值必须联合重新验证；不同 kL 下的数值不能直接沿用原有阈值的合格率结论。按膜片/采集批次划分建标和验证数据，避免把同一组图同时用于调参和验收。

当前已实现参数保存、版本区分、界面与报告展示、修改记录及默认值兼容。它提供了调参能力，具体生产参数仍需按上述步骤验证；软件不会自动根据光照变化放宽权重或阈值。

## 设置中已有的 ΔL 限值是什么意思

`MaxDeltaL`、`MaxDeltaA`、`MaxDeltaB` 是附加的独立绝对差限值。判定逻辑在 `Models/MeasurementDecision.cs`：启用的任一条件超限即判色差 NG。

- `MaxDeltaL = 0`：仅关闭附加的 `|ΔL*|` 上限，**不从 ΔE00 中去掉明度项**。
- 放宽 ΔE00 阈值：同时放宽综合色差，不等于专门降低 L 的贡献。
- 质量检查失败：输出“无法可靠测量”；不应该通过改色差权重将过曝、反光或严重失焦改判为 OK。

当前相机图像转换所得 Lab 是在项目既定 RGB 解释下的相对比较量；若用于跨相机或可溯源绝对色差，还需要验证输出色彩空间、光源与相机颜色标定。仅换一个 ΔE 公式参数不能完成跨相机标定。
