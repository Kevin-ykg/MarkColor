## 具体结构调整

- `StandardBuilder.cs` 只保留建标流程与统计。`LabValue`、`StandardSample`、`StandardChange`、`StandardBuildProblem`、`StandardBuildException` 分别位于 `Models/` 下的同名文件。
- `QualitySettings` 从 `MeasurementDecision.cs` 分离；后者保留统一结论和颜色阈值判断。`Inspection.Decision` 旁明确记录整图优先级：配准不确定 → 无法测量 → 逐点失败 → 多余点 → 通过。
- 设置提交与报告处理从 `MainWindow.xaml.cs` 分离；图像绘制从 `ImageViewport.cs` 分离。XAML 事件名称、公开入口和参数传递保持原样。
- `mark_quality.cpp` 的 `e/q/p/r` 等局部简称改为 `localEvidence/quality/point/radialDistance`；比例还原使用 `restoreScaleX/Y`。数学公式里的常用符号保留，并解释单位及公式阶段。
- Native 互操作字段按含义分组，注释紧贴字段；字段类型和顺序不变。长三元式改为清晰分支或 `switch`；重复性的 `n−1` 统计提取成具名方法。
- 保留已有规范的报告列、色差公式和配准实现，没有为了让每个文件都出现修改而重写稳定代码。
- 符号检查脚本中的内嵌 C# 提取为 `build-support/SymbolProbe.cs`，纳入 C# 格式检查；脚本保留哈希校验和探针调用。缓冲区布局偏移使用具名常量并注明释放方式。

## 维护时特别容易混淆的含义

1. **标准 Id 与检测下标**：Id 面向操作员；`ObservedIndex` 用于读取待测 `Marks/Qualities/Contours`，三者严格同下标。两张图中同一检测下标不保证是同一物理点。
2. **几何坐标与显示坐标**：算法使用原图 px；视图平移使用 WPF DIP；ROI 对外为相对整图的 0..1 比例。
3. **两种标准差**：`Mark.StdL/A/B` 是单张图内圈像素的离散程度；`StandardMark.Repeatability` 是多次拍摄的样本标准差。
4. **三种颜色值**：`MeasuredLab` 保留原始采样均值；`Value.L/A/B` 是可人工微调的判定目标；BGR 均值用于色块和粗命名。
5. **质量与颜色判定**：轮廓置信指标不是概率，BGR8 边缘亮差不是 ΔE00；测量资格不通过时不能判产品颜色合格。
6. **线程与资源**：Native 像素指针只在句柄存活时有效；复制后冻结的位图可交给 UI；线程局部错误必须在同一线程立即读取。
7. **提交与取消**：设置和建标先准备独立结果再替换状态；用户取消批量会写完已处理条目，报告写入失败则停止生产。

## 格式与验证

继续使用 `.clang-format`、`.editorconfig` 和 `format.ps1`，不引入新的第三方格式依赖。C++ 命名空间逐级缩进四空格，C# 控制分支保留大括号、方法之间留空行；XML 两空格，PowerShell 保持 UTF-8 BOM。

运行 `format.ps1 -Check` 检查格式，`build.ps1` 编译完整解决方案，`verify.ps1` 验证算法和界面。文件拆分后 C# SDK 自动纳入新源文件；Native 本次没有新增编译单元。

本次属于结构与可读性整理：不调整提取阈值、取色像素、配准算法、色差计算口径、ABI v3 或 JSON v3。整理前源码备份为 `verification/project-readability-20261016/source-before.zip`；CSV 基线和最终验证记录位于同一目录。CSV 一致性仅代表既有样本回归，不代替未见现场工况的验收。
